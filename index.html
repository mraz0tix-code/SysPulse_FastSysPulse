About

Two terminal toolboxes for Linux. Check the network, ports, disk and system from one menu.

Programs

SysPulse

Runs every command in its own kitty window and keeps the window open after the command ends.

Python · kitty · ss · nmap · fastfetch · htop

Project code: 423 lines

App on GitHub ↗

FastSysPulse

The same menus, but everything runs in your current terminal. No new windows and no pauses.

Python · ss · nmap · fastfetch · htop

Project code: 418 lines

App on GitHub ↗

Run

$ python SysPulse.py
$ python FastSysPulse.py

Needs Linux and Python 3. Menu items call ss, fastfetch, htop and nmap, so install the ones you use. SysPulse also needs kitty.

Reboot, shutdown and the Nmap scan call sudo. Scan only networks you own or have permission to test.
